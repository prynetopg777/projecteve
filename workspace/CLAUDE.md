# Eve workspace

This folder is Eve's home directory. Your own notes go here.

## Memory
Your long-term memory about the user is in `memory/profile.md` (imported below), so it's in context in every conversation.

- When you learn a lasting fact (name, preferences, people in their life, projects, routines, important dates), add it to `memory/profile.md` under the right heading with the Edit tool. Don't announce it unless asked.
- If a fact changes, update or remove the old line. Don't keep contradictions.
- Never store passwords, API keys or other secrets.
- Keep it concise, one fact per line.
